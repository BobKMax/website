# MES PROJETS — fiches publiques du site
# =====================================================================
#
# Un projet = un bloc de lignes « champ: valeur ».
# Les blocs sont séparés par une ligne de trois tirets : ---
#
#   AJOUTER un projet   copiez le modèle, tout en bas de ce fichier,
#                       et remplissez-le.
#   CHANGER L'ORDRE     déplacez le bloc. L'ordre du fichier est
#                       l'ordre du site.
#   RETIRER un projet   supprimez son bloc.
#
# Les références (01, 02…) se calculent toutes seules à partir de la
# position dans le fichier : il n'y a jamais rien à renuméroter.
#
# Tout ce fichier est PUBLIC : il est en ligne, lisible par tous.
# N'y écrivez jamais de maître d'ouvrage, de montant, de contact ni de
# note : ces informations vont dans prive/fiches-privees.txt.
#
# LES CHAMPS
#   id          obligatoire — identifiant permanent du projet :
#               année-lieu-motclé, en minuscules, sans accents, avec
#               seulement des lettres, des chiffres et des tirets.
#               Ex. 2024-lyon7-logements. Il ne change JAMAIS, même si
#               le titre ou l'année changent : les sélections et les
#               fiches privées s'y rattachent. Deux projets ne peuvent
#               pas avoir le même.
#   titre       obligatoire — sans titre, le bloc est ignoré.
#               Affiché tel quel, mention [LFA.architectes] comprise.
#   lieu        Lyon VII, Charly, Villeurbanne…
#   annee       2025
#   programme   sert de filtre sur le site. Réutilisez les mêmes mots
#               d'un projet à l'autre : Logement, Équipement,
#               Rénovation. Un mot nouveau crée un filtre nouveau.
#   surface     412 m² SDP
#   statut      écrit librement, affiché tel quel. Mots conseillés :
#               étude, compétition, en cours, construit, mission amo,
#               non réalisé. Un mot nouveau est accepté ; gardez
#               toujours la même orthographe pour un même statut.
#   taille      largeur de la vignette dans la grille : 1 = normale,
#               chaque cran ajoute environ 25 %. Absent = 1.
#   materiaux   pas encore affiché. Liste séparée par des virgules :
#               bois, paille, terre…
#   accroche    pas encore affiché. Une phrase.
#   texte       pas encore affiché. Paragraphe de présentation.
#   mise_en_page  pas encore utilisé. Force une mise en page dans les
#               PDF de l'atelier ; laissez vide.
#   image       une ligne par image, voir ci-dessous.
#
# Un champ vide ou absent s'affiche en tiret cadratin (—).
# Ne mettez pas de guillemets autour des valeurs.
# Les lignes commençant par # sont ignorées.
#
# LES IMAGES
#   Déposez-les dans le dossier photos/, puis écrivez une ligne par
#   image :
#
#       image: fichier | rôle | crédit
#
#   - fichier  le nom exact, extension comprise ;
#   - rôle     un de ces mots : couverture, exterieur, interieur,
#              rendu, plan, coupe, detail, chantier, maquette.
#              « rendu » = image de synthèse : ne l'appelez jamais
#              exterieur ou interieur, une image de synthèse ne doit
#              pas passer pour une photo de réalisation ;
#   - crédit   facultatif, ex. © Prénom Nom.
#
#   L'ordre des lignes est l'ordre d'affichage. La vignette du site est
#   la première image de rôle « couverture », à défaut la première image.
#   Sans aucune image, un aplat bleu s'affiche à la place.
#
#   Les vignettes gardent le format de la photo. Visez 1200 px de large
#   au minimum. Si vous remplacez une photo, changez son nom de fichier
#   (halle-01.jpg devient halle-01b.jpg) : les navigateurs gardent les
#   photos une semaine en mémoire.
#
#   L'ancien champ « photo: » est encore lu, pour ne rien casser, mais
#   n'est plus à utiliser.
#
# =====================================================================
